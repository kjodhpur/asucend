# asucend (Ascend)

Cubbie Skill for Arizona State University students. Turns getting involved on campus into a weekly leveling game: real ASU event missions, photo proof, XP tracks, and a Sunday stats card.

## What it does

1. One-time setup (interests, comfort 1–5, free times, ASU campus)
2. Weekly quest drop from real ASU events (web search + optional Google Calendar)
3. Nudge 1 hour before; add to calendar only after yes
4. Photo proof → XP on Networking / Career / Academic / Wellness / Exploration
5. Adapts difficulty; Sunday shareable stats card
