# Bundled card fonts

Used by `scripts/card.py --png` so reward cards render identically in a sandbox with no system fonts.
All are SIL Open Font License 1.1 fonts from https://github.com/google/fonts (licence texts alongside).

| File | Source | Notes |
| --- | --- | --- |
| Oswald-Regular/Bold.ttf | ofl/oswald | Static instances (wght 400/700) of the variable font |
| Nunito-Regular/Bold/ExtraBold.ttf | ofl/nunito | Static instances (wght 400/700/800) of the variable font |
| SpaceMono-Bold.ttf | ofl/spacemono | Unmodified |
| Cinzel-Regular/Bold.ttf | ofl/cinzel | Static instances (wght 400/700) of the variable font |
| Alegreya-Regular/Bold.ttf | ofl/alegreya | Static instances (wght 400/700) of the variable font |

None of these licences declare a Reserved Font Name, so the instanced files keep their family names.
